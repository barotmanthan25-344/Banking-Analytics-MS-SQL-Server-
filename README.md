# Banking Analytics Project (MS SQL Server)

## Project Overview
This project focuses on analyzing banking customer and loan data using SQL Server. The objective is to generate business insights related to customer behavior, loan performance, credit risk, and portfolio management.

## Tools Used
- MS SQL Server
- PowerPoint

## SQL Concepts Applied
- Joins
- Common Table Expressions (CTEs)
- Window Functions
- Aggregate Functions
- Subqueries
- Stored Procedures

## Key Business Analysis
- Customer Segmentation
- Loan Portfolio Analysis
- Credit Score Analysis
- NPA (Non-Performing Asset) Monitoring
- Risk Assessment
- Bank Performance Analysis
- Regional Banking Trends

## Project Files
- SQL Queries
- Banking Analytics Dataset
- Project Presentation (PPT)

## Outcomes
Generated actionable insights to support data-driven decision-making, customer profiling, loan risk assessment, and portfolio performance evaluation.
